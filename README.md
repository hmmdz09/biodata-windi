# 🌸 Windi Rihanafsa • Portfolio & Personal Website

> Website biodata dan portofolio personal **Windi Rihanafsa** (Mahasiswa Pendidikan Ilmu Komputer - Universitas Pendidikan Indonesia) dengan desain modern, aesthetic pink, dan pemutar musik terintegrasi lagu *"everything u are"* oleh Hindia.

---

## ✨ Fitur Unggulan

- **🌸 Aesthetic Pink Theme:** Nuansa soft rose blossom (Light Mode) dan velvet midnight pink (Dark Mode) dengan efek glassmorphism dan pendaran halus.
- **📸 Penataan Foto Khusus:**
  - Hero Spotlight menampilkan foto Windi dengan kartu Spotify player terintegrasi.
  - Section Dokumentasi menampilkan 2 foto kenangan di UPI (Angkatan di Villa Isola & Praktikum di Lab Komputer) lengkap dengan fitur Lightbox Fullscreen.
- **🎵 Music Player "everything u are" - Hindia:**
  - Pemutar audio native dengan kontrol Play/Pause, scrubber waktu, equalizer animasi, dan volume slider.
  - Lirik lagu tersinkronisasi (*synchronized lyrics*) otomatis mengikuti alunan musik.
  - Floating bottom dock player saat scrolling.
- **👋 Interactive Greet Modal:** Tombol sapaan ramah dengan animasi konfeti pink dan melodi chime.
- **📱 Responsif Penuh:** Tampilan optimal di perangkat smartphone, tablet, laptop, dan monitor desktop.
- **⚡ Super Cepat:** Dibuat menggunakan HTML5, Modern CSS, dan Vanilla JavaScript murni tanpa framework berat.

## 🚀 Cara Menjalankan Secara Lokal

Cukup buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
# Menggunakan npx serve
npx serve .

# Atau menggunakan Python
python -m http.server 8000
```
